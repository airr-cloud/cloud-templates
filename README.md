# Cloud Templates

A collection of reusable cloud infrastructure templates/recipes.

## Available templates

| Template | Description |
|---|---|
| [aws/eks-mlcb](aws/eks-mlcb/) | Terraform template for an AWS EKS cluster with GPU worker nodes backed by EC2 Capacity Blocks for ML. Includes a test mode using a standard On-Demand Capacity Reservation. |

## Usage

Open the template directory and follow its README for prerequisites, configuration, deployment, and cleanup instructions.
